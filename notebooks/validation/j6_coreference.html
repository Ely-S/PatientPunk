Judgement ⑥ — coreference: does the model use upstream context?¶

The weakest judgement to validate — the frozen run had zero coreference items (a parent-id defect), so we probe it directly by context ablation: classify each (comment, drug) with its parent context and without. A model that resolves coreference should change its answer when the context is removed on context-necessary items (the drug is only in the parent), and not on control items (the drug is already in the comment, so the context is redundant — the noise floor). The gap between the two is the coreference signal.

21 of 22 models are scored. Left out for having no usable answer on more than 25% of items: glm-4.7-flash (71%). Panel numbers, rankings and verdicts below use the scored models only.

(loaded — 4451 usable classifications, 21 scored models; 16 context-necessary pairs)

1. Does removing context change the answer — necessary vs control?¶

Per model: how often the sentiment/signal flips when the parent context is ablated, on context-necessary items vs control items.

Context-necessary items change 25% of the time when the parent is removed, vs 21% for control items — a +4% gap in the expected direction, but a weak one. Two reasons to read it cautiously: the control change-rate is 21% — removing redundant context shouldn't move the answer at all, so the models are noticeably unstable to prompt edits, and the coreference signal sits only ~4 points above that noise floor. And the context-necessary group is tiny (11–16 context-necessary pairs per model), so the gap is suggestive, not conclusive. Best read: a hint that models use the reply chain, not proof — ⑥ stays the least-validated judgement.

2. Which models depend on context most¶

Models with a large necessary-minus-control gap resolve coreference strongly (they lean on the parent when the drug isn't local). A small gap means either the model ignores upstream context (a coreference weakness) or it guesses locally regardless. A model whose control change-rate is high is unstable — its answer wobbles even when context is redundant, which is noise, not coreference. 3. Verdict¶

  • Weak-positive, not a clean pass. The gap is in the right direction (25% necessary vs 21% control, +4%), so models lean on the reply chain — but the effect is small and rides on only 11–16 context-necessary pairs per model. ⑥ remains the least-validated of the eleven.
  • The 21% control change-rate is a red flag of its own — removing redundant context shouldn't change the answer, so the classifier is fairly unstable to prompt edits (temperature is pinned to 0, so this is prompt-sensitivity, not sampling). That instability, not coreference, may be the bigger reliability story.
  • **We could only ever show use, not *correctness*** — ablation shows the model depends on context, never that it resolves it right. With no coreference gold and a defect-zeroed frozen run, this probe on real items is the honest ceiling for ⑥.
  • Recommendation: widen the context-necessary set (construct thread-structure items) and drive down the control change-rate (prompt-stability check) before treating coreference as validated.

Limitations¶

  • Change ≠ correctness — ablation shows the model depends on context, not that its resolution is right. With no coreference gold, "uses context" is the strongest claim available (the plan's stated ceiling for ⑥).
  • Context-necessary is inferred from whether the drug string appears in the comment text — a surface heuristic; a drug referred to only by pronoun/synonym in the comment could be mislabelled.
  • Depends on the parent_context field in the IRR frame (280/300 pairs) at depth 2; deeper chains untested.
  • Measures whether a resolution step fires, not any treatment effect. Not medical advice.
