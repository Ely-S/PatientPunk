# A1 Prompts

Prompts in this folder are versioned inputs to the A1 comment-coding
instrument. Each prompt version should be tested on the same frozen sample IDs
before it is promoted for A2.

Current prompt:

- `comment_coder_v0.1.md`: baseline structured-output prompt for target-author
  health-claim coding with strict context attribution rules.

Rendered prompt inputs are generated by code, not stored here. The prompt file
is intentionally static so run manifests can hash and cite it.
